# Audit bug fixes (2026-10-29), branch 1.21.11

Mirrored from the 1.14.4 commit `03be7448`. Written in a session with no JDK, no Minecraft/NeoForge jars and no network: **nothing here was compiled or run.** Only the parse-level `syntaxcheck.sh` passed on every changed file; every API call was copied from code that already exists on this branch (see the per-fix notes), but `./gradlew build`, both suites and the manual rows (`TESTING_CHECKLIST.md` section G) are still to be done.

Blocked: none. Not in scope (as on 1.14.4): Peace Candle churches in all villages, Imbuing Station / Inventory Tester drops, Tincture recipe.

## Per fix
- **AF1 Redstone Tool.** `RedstoneObserverBlock` and `BasicRedstoneInterfaceBlock` override `useItemOn` (shape copied from `SoundBoxBlock.useItemOn`): with a `RedstoneToolItem` in the used hand it returns `InteractionResult.PASS`, which skips `useWithoutItem` (the GUI) so the item's `useOn` links; otherwise `TRY_WITH_EMPTY_HAND` (the block default). Unverified: that `PASS` from `useItemOn` falls through to `Item.useOn` in 21.11 (the dispatch in `debug/BlockUse` only reproduces the GUI half).
- **AF2 Online Detector.** `getPlayerByName` ignores case; the found `ServerPlayer.getGameProfile().name()` must equal the stored name. Test `behavior.online_detector.matches_the_player_name_case_sensitively` added (RemainingBehaviorTests).
- **AF3 Lotus Seeds.** `LotusSeedsItem.useOn` also requires `groundState.is(Blocks.FARMLAND)`. `LotusBlock.mayPlaceOn` untouched so natural lotus survives.
- **AF4 Peace Candle vs slimes.** `AsmHandler.overrideSpawnResult`: the candle loop moved into a MONSTER block in front of the `EntityType.SLIME` early return. Test `coremod.spawn.peace_candle_denies_slimes_even_inside_an_unpowered_slime_cube_chunk` added (CoremodTests, calls the hook directly). The Java class processor is untouched.
- **AF5 Spectre Lens.** `SpectreLensHandler` stores `dimension id string -> (owner -> entry)` in the overworld store; the key is `level.dimension().identifier().toString()` (as `PortkeyItem`/`BiomeRadarTileEntity`), the tick compares it with `player.level().dimension().identifier().toString()` (as `RandomThings.java:408`). NBT entries carry a `dimension` string; entries without it are dropped on load (the lens block entity re-registers within 80 ticks). `removeLens`/`addLens` take the dimension as first argument; the only callers are in `SpectreLensTileEntity`. 1.14.4 used the integer dimension id; here the identifier string is the equivalent.
- **AF6 Ender Letter.** `EnderLetterHandler.get(Level)` uses `world.getServer().getLevel(Level.OVERWORLD).getDataStorage().computeIfAbsent(TYPE)` (same as `SpectreLensHandler.get`); `ServerLevel` import removed.
- **AF7 Sound Box / Slime Cube.** `powered` written/read as a boolean in the `rtSaveAdditional`/`rtLoadAdditional` helpers (SoundBox) and in new `saveAdditional`/`loadAdditional` wrappers with the same helpers (Slime Cube, copied from `OnlineDetectorTileEntity`); `getBooleanOr("powered", false)`.
- **AF8 Advanced Redstone Torch.** Both setters call `setChanged()`.
- **AF9 Potion Vaporizer.** Block `onRemove` is gone on this branch: `PotionVaporizerBlock.rtOnRemove` (copy of `IronDropperBlock.rtOnRemove`, `Containers.dropItemStack` over `itemHandler()`) is called from a new `PotionVaporizerTileEntity.preRemoveSideEffects` (copy of `IronDropperTileEntity`).
- **AF10 Ender buckets.** After `drainSource`, `fill(drained, FluidAction.SIMULATE)` on the bucket (a one-item copy in `EnderBucketItem`, the stack itself in `ReinforcedEnderBucketItem`, handler from `CapUtil.fluidItem`); if the whole amount does not fit the block is put back with `world.setBlock(pos, state, 3)`. Unverified: `FluidAction.SIMULATE` is not used anywhere else on this branch (only `EXECUTE`, same enum, imported already); the restore may cause a neighbour update blip.
- **AF11 Eclipsed Clock.** Sneak-decrease wraps with `((t % 24000) + 24000) % 24000`; the dropped item gets `targetTime` in its custom data (`StackTag.getOrCreate/set`; the item model `RTItemModels` already reads `targetTime` through `StackTag`), placement restores it with `StackTag.contains/getInt`.
- **AF12 Stable Ender Pearl.** Only reads the UUID when `player-uuid` exists; `IllegalArgumentException` is caught and treated as unbound.

## Unverified points
Compile errors are possible anywhere (no compiler); the `PASS` fall-through (AF1) and `FluidAction.SIMULATE` (AF10) are the two calls without a proven sibling on this branch. Tests were added only for AF2 and AF4 (the shapes exist here).
