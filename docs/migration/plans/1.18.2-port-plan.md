## Milestones

1. **M0 Toolchain** - done 2026-10-15: project resolves; 15,227 compile errors.
2. **M1 Rename** - done: 13k automatic edits (types, methods, fields, imports), inline FQNs, `BlockPos.offset(Direction)` -> `relative`, `Player.inventory/abilities`, `Entity.xRot/yRot` accessors. Errors in the first javac phase: 15,227 -> 757 (javac reports later phases only once these are gone, so more will appear).
3. **M2 BlockEntity** - scripted: constructors `(pos, state)`, `saveAdditional`/`load(tag)`, `EntityBlock.newBlockEntity` + `getTicker` for the 19 ticking blocks (`util/Tickers`). Still manual: sync packets, `Level.setBlock`/`remove` call sites, `BlockEntityType` registration leftovers, `SavedData` (`DimensionDataStorage.computeIfAbsent`).
4. **M3 Rendering** - `RenderSystem.color4f`/`TextureManager.bind` (73 uses) -> shaders (`setShaderColor`, `setShaderTexture`), `BlockEntityRenderer` context, `ItemRenderer`, screens (`addButton` -> `addRenderableWidget`, `tick`), particles.
5. **M4 Worldgen / dimension** - `Holder<Biome>`, placed features (`FeatureDecorator` gone), structure pools (`StructureTemplatePool` package moved), `ChunkGenerator` codec/`WorldGenRegion`, world height -64..320 (lighting sweep, Spectre dimension, Glowing Mushroom depth).
6. **M5 Forge API moves** - `ToolType` removed (tags), `IForgeContainerType` -> `IForgeMenuType`, `RenderingRegistry`/`ClientRegistry`, `GuiScreenEvent` -> `ScreenEvent`, `RenderWorldLastEvent` -> `RenderLevelStageEvent`, `ModelLoader`.
7. **M6 Coremods** - the 15 JS transformers need Mojang class/method names (+ the 1.18.2 JS sandbox blocks `Java.type('java.lang.System')`).
8. **M7 Boot + suites** - client/server suites, resource audit, production (SRG) check, hand-test list.

M0-M6 done in code, M7 started: `./gradlew build` is green and the **dedicated-server dev suite runs: 349 passed / 0 failed / 2 skipped (of 351)** (`RT_AUTOTEST=true RT_AUTOTEST_EXIT=true ./gradlew runServer`). Nothing is committed. The client has not been started yet.

### What changed (beyond the mechanical Mojang rename)

- **Block entities:** `(pos, state)` constructors, `saveAdditional`/`load(tag)`, `EntityBlock.newBlockEntity` + `getTicker` (19 ticking blocks, helper `util/Tickers`), `ClientboundBlockEntityDataPacket.create(this)`, `SavedData` handlers with a static `loadFrom` factory.
- **Forge/vanilla API moves:** `IForgeMenuType`, `ScreenEvent`, `RenderLevelLastEvent`, `ServerStartingEvent` & co, `EntityRenderersEvent.RegisterRenderers` (block-entity and entity renderers are registered there; renderers take a `Context`), `IItemRenderProperties` for the Portkey item renderer, `IBlockRenderProperties` for the Diaphanous break particles, `ForgeModelBakery.addSpecialModel`, tool types -> `mineable/*` block tags (`data/minecraft/tags/blocks/mineable/{shovel,axe}.json`), durability bar API, `getFriction`.
- **Rendering:** `RenderSystem.setShader*` instead of `bind`/`color4f`; the end-portal entity uses the fixed-layer `RenderType.endPortal()` (the per-distance pass count is gone); `AlphaVertexBuilder` implements `defaultColor`/`unsetDefaultColor`; `ScreenWidgets.buttons(screen)` replaces `Screen.buttons`; narration stubs on the custom list entries and the multiline widget.
- **Worldgen/dimension:** features are `PlacedFeature`s (`RarityFilter`, `InSquarePlacement`, `HeightmapPlacement`, `BiomeFilter`), `Feature.place(FeaturePlaceContext)`, heights use the level's min/max build height. Glowing Mushroom keeps the original patch-centre roll from y 0 (not -64): with the roll from -64 it was about 4x rarer than on 1.16.5; the natural rate is now 12 of 300 chunks (4%), the same as 1.16.5. Ancient Furnace biome conversion writes each chunk section's paletted biome container (per 4x4x4 cell) and resends the chunk with `ClientboundLevelChunkWithLightPacket`; its cold->warm table uses the 1.18 biome names (the *_HILLS/*_MOUNTAINS variants are gone). Spectre: `DimensionType`'s constructor is private, so the type is `data/randomthings/dimension_type/spectre.json` (min_y 0, height 256, as before); only the chunk generator codec is registered from code; the dimension is still added to the world at `ServerAboutToStartEvent`.
- **Peace Candle church:** the pool registry is frozen at server start, so `PeaceCandleChurchPool` swaps the value inside the `Holder.Reference` by reflection (SRG `f_205752_`); the church piece gets this world's own `minecraft:empty` processor-list holder (a builtin one is rejected as "not valid in current registry set").
- **Coremods (15):** class/method names retargeted (Mojang name or SRG `m_` id, same dual-name check as before) and each anchor re-read in the 1.18.2 bytecode. Changes that were not a rename: `LevelRenderer` biome lookups now return `Holder<Biome>` (`AsmHandler.getBiomeForRainRender` returns a `Holder`), `BlockState.getFriction` (Forge) instead of `getSlipperiness`, the armor layer's `renderModel` is now an `invokevirtual` matched by owner + descriptor, the `VertexLighterFlat` colour array moved from local 3 to local 4, glint getters are `glint()/entityGlint()/...`. Verified on the dev client/server and on the production (SRG) jar (suites + render scenes); the visual result of the glint tinting is still unseen.
- **Reflection:** `ObfuscationReflectionHelper` names are SRG ids (`f_`/`m_`); `docs/migration/tools` has the lookup helper.
- **Tests:** the world generation tests drive the 1.18 generator by hand (`WorldgenTests.generateTerrainAndCount`: 9x9 chunk patch, wide placeholder regions for surface building and carvers, a structure manager that knows no structures - the real one deadlocks against the server thread).
